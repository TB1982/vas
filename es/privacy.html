Política de Privacidad de VAS

Última actualización: 2026-04-03

VAS — Visual Annotation Studio (en adelante, «la App») respeta tu privacidad.

Recopilación de datos

La App no recopila, almacena ni transmite ningún dato personal. Todo el procesamiento de imágenes (incluidos el reconocimiento de texto por OCR y los análisis de enmascaramiento de privacidad) se realiza localmente en tu dispositivo y nunca se envía a ningún servidor.

Permisos del sistema

La App requiere permiso de grabación de pantalla para realizar la captura de pantalla. Este permiso se utiliza únicamente para las capturas de pantalla y para ningún otro fin.

Acceso a la red

La App utiliza una conexión de red solo cuando comprueba si hay actualizaciones. No se sube ningún dato del usuario.

Servicios de terceros

La App no utiliza ningún servicio de análisis, publicidad o seguimiento de terceros.

Contacto

Para cualquier consulta relacionada con la privacidad, ponte en contacto con: nova@yoursvas.app
